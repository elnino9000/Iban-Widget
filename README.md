# IBAN Widget
Ana ekran widget'ı: banka simgesine bas, IBAN WhatsApp'a hazır yazılı gelsin.
APK: Releases > "IBAN Widget (son sürüm)" > iban-widget.apk

Yedek: uygulamanın altındaki "Yedeği paylaş" ile tüm bilgileri bir metin olarak kendine gönder; yeni telefonda kopyalayıp "Yedeği panodan geri yükle"ye bas. İstersen mesajın ilk satırına ad soyad da eklenir.
